# Quem Sou Eu? – Jogo Web

Projeto desenvolvido com o objetivo de praticar **desenvolvimento front-end e lógica de jogo**, criando uma aplicação interativa inspirada em jogos de adivinhação de figuras públicas.

O jogo foi desenvolvido utilizando **React**, **JavaScript**, **HTML** e **CSS**, focando na criação de uma experiência dinâmica e interativa para o usuário.

## 🚀 Tecnologias

* React
* JavaScript
* HTML
* CSS

## 📚 Sobre o Projeto

O **Quem Sou Eu?** é um jogo onde o usuário precisa adivinhar qual é a **figura pública** apresentada na tela.

No início da partida, a imagem da pessoa aparece com um **forte efeito de blur**, dificultando sua identificação. A cada tentativa incorreta do usuário, o nível de blur diminui, revelando gradualmente a imagem.

O jogador possui **até 7 tentativas** para acertar a identidade da figura. Caso o jogador utilize todas as tentativas sem acertar, a partida é encerrada e o jogo é perdido.

## ⚙️ Funcionalidades

* Sistema de tentativas para o jogador
* Limite de **7 tentativas por partida**
* Efeito de **blur progressivo na imagem**
* Redução do blur a cada tentativa incorreta
* Verificação de acerto ou erro
* Sistema de vitória e derrota
* Interface interativa desenvolvida com React
